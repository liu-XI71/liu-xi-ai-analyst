# Integration contract v1

New independent project. Never modify old portfolio repositories or URLs.
Python FastAPI app package. Domain modules: app/domains/growth.py and repurchase.py.
Each exports metadata() -> dict, build_database(path: pathlib.Path) -> None, analyze(request: dict, db_path: pathlib.Path) -> dict. Prefer standard-library sqlite3 for simple portable data tools. Deterministic synthetic data explicitly labeled, fixed seed. Growth may reuse existing pure statistical functions with attribution.
Input: question:string, domain:growth|repurchase, task:diagnose|experiment|report|segment, start/end/compare_start/compare_end optional ISO dates, filters dict. Domain functions must validate supported tasks and dates, never ignore them.
Output: status:completed|needs_clarification|insufficient_data; title; summary; metric_contract:dict; kpis:[{id,label,value,unit,previous?,delta?}]; tables:[{id,title,columns:[string],rows:[dict]}]; charts:[{id,title,type:line|bar|waterfall|scatter,x_key,y_keys:[string],data:[dict],unit?}]; findings:[{kind:fact|hypothesis|action,text,evidence_ids:[string]}]; evidence:[{id,label,sql,parameters:dict|list,rows:[dict],source,metric_version}]; trace:[{tool,status,description,duration_ms?}]; limitations:[string]; suggestions:[string]. Top-level optional clarification:{question,options:[string]}. All report facts computed deterministically. Never invented historical business results or claimed uplift.
metadata: {id,name,description,data_source,data_range:{start,end},default_request:dict,metrics:[dict],tables:[dict],examples:[{question,task}]}
Frontend served at /; relative /api/v1. GET /api/v1/catalog => {domains:[metadata],model:{configured,mode,model},version}. POST /api/v1/analyze input above plus mode:demo|live returns full output plus run_id,mode,created_at. GET /api/v1/runs/{id}; GET /api/v1/runs/{id}/report?format=html|md; POST /api/v1/sql/preview controlled SQL. GET /api/health. GET /api/v1/evaluations summary.
Mode demo is clearly deterministic semantic-query demo, never labeled live LLM. Mode live calls OpenAI for intent/tool planning and bounded function calls; no credential => explicit failure, never silent fallback.
Frontend must handle loading, error, clarification, stale result clearing, mobile, keyboard. Content order portfolio: growth Agent; business cases; reusable CSV and repurchase tools. Separate workbench views growth/repurchase/evaluation/about.
