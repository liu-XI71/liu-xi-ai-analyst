# 评测方法与结果解释

## 分层验证

| 层 | 方法 | 可以证明的范围 |
|---|---|---|
| 业务计算 | 独立读取原始用户、事件、活动、订单；集合与时序聚合 | 当前合同下的数值、窗口、分母和去重 |
| 数据异常 | 缺批次、未知schema、无效时间、事件顺序、成熟边界 | 对指定故障的阻断与恢复 |
| 实验方法 | 分配/曝光/结果复算、SRM、功效、区间和围栏 | 固定实验合同与统计实现 |
| SQL证据 | 重放实际SQL及参数，对比结果行 | 证据可复现；不自动证明每句解释的语义 |
| API与报告 | 请求/回读/报告/错误/反馈/管理接口 | 应用合同和导出链路 |
| 模型协议 | 测试替身驱动工具循环、参数拒绝、失败与退出 | 协议行为；不等于真实模型准确率 |
| 真实模型 | 实际Provider调用、问题集与重复执行 | 仅在完成实测后记录该模型和题集的结果 |

## 公开回归

原主集60题与追加审计10题保留首次记录及修复后结果；本版新增公开V2业务任务与独立事件基准。已运行、已公开或用于修复的题不能再称未见盲测。结果文件中的分母与适用范围比单一百分比更重要。

```bash
python -m pytest -q
python scripts/evaluate.py
python scripts/evaluate.py --suite audit
python scripts/evaluate_v2.py
```

V2题集和结果位于 `evals/v2-cases.json`、`evals/v2-results.json`。默认模式直接执行实际Pydantic请求与业务引擎；其耗时是引擎时间，不含用户阅读、远端网络或真实模型生成时间。

## 真实模型评测

模型实测使用独立的结果文件。未配置凭据时状态为 `not_run`，样本数为0，不复用确定性结果。协议测试中的测试替身在结果中明确显示为 test-double，live_verified=false。

真实模型评测应分开报告：参数与指标选择、可回答任务正确性、应澄清/停止行为、错误拒答、证据支持、重复稳定性、时延与实际token。若m个可回答任务各运行3次，执行成功率的分母是3m，三次均成功的任务稳定率分母是m；澄清题另算。

真实提效研究比较手工SQL/Python、现有确定性工具、AI三种方式，并记录人工检查和修改时间。本版本不预设节省百分比，不把技术完成率当作业务正确率或真实经营收益。

## 复核原则

关键指标使用独立实现验算，重要决策结论需要检查证据是否支持。模型评分可辅助，不能作为唯一判定。变更后修复并重跑失败路径；固定题通过后不继续反复调参追逐同一分数。
