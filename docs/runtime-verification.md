## 本轮修正

1. 页面和报告分别标记静态案例、Python规则分析、测试替身、模型调用未核验、已核验模型调用。
2. 已核验模型调用须同时满足 `mode=live`、`provider=OpenAI`、`live_verified=true`；请求模式本身不作为调用证明。
3. 模型必须登记分析计划，且不能修改用户显式指定的任务、日期或筛选条件。连续违规停止执行。
4. 规则入口识别的文字日期、设备、渠道、版本、地区和预算与表单不一致时，先返回澄清，不计算另一组默认条件。该校验是有限规则，不承诺解析任意自然语言。
5. 无Key或Provider失败返回错误并记录脱敏技术状态，不返回静态案例或规则计算冒充模型结果。
6. 文案分别记录计算事实、验证事项和后续行动；保留数据来源、质量状态和统计适用范围。报告附录记录模型来源和用量完整性；未知值不写为零。

## 结论使用范围

- 指标、分解、图表、实验统计与名单规则可用于当前合成数据集的复算和方法展示。
- 观察性切片与版本关联用于安排核查，不能作为某项改动造成留存变化的因果结论。
- 实验结论依赖预注册指标、随机分配、成熟窗口和数据质量；通过门槛仅进入人工评审。
- 复购输出为候选与留出计划，未执行触达，没有已观测营销增量。
- 真实业务应用需接入获准的数据并核验口径；真实模型还需凭据配置后的条件提取、歧义、拒绝、工具执行及答案正确性验收。
