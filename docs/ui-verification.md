# 界面与资源验证记录

版本：0.2.0。验证日期：2026-09-19。

本版本包含作品总览、增长诊断、实验评审、复购运营、监控与运行、完整案例、评测与验证、方法与资料八个视图。此记录限定于实际执行的源代码、组件合同、静态资源和 HTTP 检查。

## 已执行检查

本版9组无依赖Node合同检查及1组本地HTTP集成检查通过。HTTP检查包括目录与评测、动态分析、两种报告下载、CORS预检及无效反馈拒绝，不调用真实模型。

- JavaScript 模块语法检查；入口资源和 ES 模块引用存在。
- 使用13份实际导出快照调用结果组件，检查关键字段、质量阻断、决策、SQL证据及报告链接。
- 缺失与未成熟值保留为空；数值不出现NaN，嵌套对象不直接显示为object Object。
- 动态文本转义；恶意文本不成为可执行脚本。
- HTML、Markdown、JSON导出路径与场景对应。
- 服务端动态模式的反馈字段与前端表单对齐。
- 模型凭据未配置显示未执行；协议替身不计为真实模型验证。
- 公开回归优先展示V2题集，旧60题与10题另列，并保留首轮记录。
- API访问令牌仅保存在内存，拒绝把sk-模型密钥当作部署令牌；远端API地址要求HTTPS。
- 本地一体化预览的健康接口、首页与静态资源可通过HTTP读取。

可重复运行：

```bash
node --check web/app.js
node --check web/components.js
node --check web/ui.js
node tests/check_frontend.mjs
python -m pytest -q
```

## 交互合同

静态页面只切换固定场景，问题和参数与对应快照保持一致。连接API后可以提交新的日期、维度和问题。参数变化时旧结果明确失效；取消请求和迟到响应不得覆盖新输入。实际报告保存同次运行的指标、决策、图表与证据。

界面提供侧栏窄屏布局、跳到正文、方向键结果页签、表格局部滚动与打印样式。

## 验证范围

本版未执行浏览器截图、DOM交互自动化或多设备视觉验收，源代码与组件合同通过不等于已完成这些检查。前一版本的浏览器记录不作为此版本的浏览器验收证据。真实模型端到端验收与云端后端验收需要对应账户配置，状态单独列示。
