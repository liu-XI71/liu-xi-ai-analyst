## 状态与访问控制设计

- 编辑问题、模式、日期或筛选后，旧结果立即清除。正在等待的客户端请求作废，其迟到响应不会覆盖新输入。
- 离线页面锁定问题与参数，并同步保存快照中的原问题。离线按钮读取真实保存结果，不假装执行新问题。
- 模型未配置时，真实 OpenAI 模式不可选；确定性演示和静态回放均明确标识。
- API 地址可以保存在浏览器本地；部署访问令牌只在当前页面内存中保存，刷新即清除。
- 访问令牌字段不接受 `sk-` 开头的模型密钥；真实 OpenAI API Key 应在后端配置。
- 窄屏侧栏关闭时使用 `inert` 与 `aria-hidden`，避免隐藏导航仍可被键盘聚焦。结果页签支持左右方向键、Home 与 End。
