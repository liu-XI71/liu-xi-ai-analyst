| 项目 | 定义 |
|---|---|
| 数据来源 | 种子 71 的合成注册、活动和随机实验数据；非企业真实经营数据 |
| 数据范围 | 2026-07-06—2026-09-06；日期按 Asia/Shanghai 自然日 |
| 固定快照 | 2026-09-06；成熟注册队列截止 2026-08-30 |
| 分析单位 | 用户；`growth_users.user_id` 唯一 |
| 注册队列 | `growth_users.signup_date`，本期与对比期均含首尾日期 |
| 次 7 日内留存分子 | 在注册后第 1—7 日任意一天至少有一次活动的用户数 |
| 次 7 日内留存分母 | 注册日 +7 日 ≤ 快照日的去重注册用户数 |
| 不属于分子 | 注册当日活动；第 8 日及之后活动 |
| 精确 D7 | 仅注册后第 7 日活动；与次 7 日内留存不等价，本工具没有该指标接口 |
| 维度 | channel：organic / paid_search / social / referral；device：android / ios / web |
| 实验窗口 | 2026-08-17—2026-08-30 的注册用户；独立随机 1:1 分组 |
| 实验提升 | 处理组留存率 − 对照组留存率，单位百分点，不是相对百分比 |
| 实验统计 | 双侧两比例 z 检验；未合并标准误正态近似 95% CI |
| 实验 SRM | 预设分配 1:1；卡方 1 自由度，p <0.01 标记异常 |
| 样本门槛 | 两组各 ≥200，各组留存和未留存人数均 ≥10；不是正式功效分析 |
| 业务门槛 | 绝对提升点估计 ≥1.5pp；95% CI 下界 >0；增量激励成本 ≤0.35 元/用户 |
| 7 日收入 | 每用户在合成 7 日窗口产生的收入，CNY；仅描述性，不输出盈利结论 |

两表关系：`growth_users` 一对多 `growth_activity`，活动主键为 `(user_id, activity_date)`。留存 SQL 使用 `EXISTS`，不能把连接后的活动行数当成用户数。实验用户在分母保留，不能先筛选「有活动」再比较。

## 对称分解

对每个渠道 × 设备分层 j，w 表示该分层用户占比，r 表示留存率，0/1 表示对比期/本期：

- 结构贡献：`(w1 - w0) × (r1 + r0) / 2 × 100` 个百分点。
- 表现贡献：`(r1 - r0) × (w1 + w0) / 2 × 100` 个百分点。
- 所有分层两项之和必须等于总体留存变化。

某分层在一期没有用户时，不估计不存在的留存率。计算分解时以观察到的另一期间留存率作计算约定，贡献全部归入结构项；展示缺失期留存率为 null，并说明这一约定。该方法不是因果归因。
